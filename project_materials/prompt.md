Use the attached reference image as the primary visual and layout reference for the website.

Build a premium, immersive, highly interactive website for Poddar Jindal Agro Mills Pvt. Ltd., a mustard oil brand.

The reference image represents the desired visual direction, color palette, composition, typography hierarchy, product presentation, imagery style, and overall premium Indian food-brand aesthetic.

Do NOT simply reproduce the screenshot as a static webpage. Use it as the design foundation and create a much more immersive, modern and interactive experience.

The website should feel like a combination of:

Premium Indian food brand
Traditional agricultural heritage
Modern food-processing technology
Natural/organic visual storytelling
Editorial luxury brand website
Smooth Framer/Awwwards-style interactions
Strong product storytelling

The most important objective is:

Tell the complete journey of a mustard seed — from the mustard field → carefully selected seed → cold pressing → pure mustard oil → quality control → bottling → finally reaching the Indian kitchen.

The visitor should understand this story naturally just by scrolling.

23. PERFORMANCE

This is extremely important.

The site will contain many animations and large images, so optimize aggressively.

Use:

Lazy loading
WebP/AVIF images
Responsive image sizes
will-change only where necessary
GPU-friendly transforms
Avoid expensive continuous JS calculations
Use IntersectionObserver where GSAP isn't necessary
Avoid animation on every DOM element
Respect prefers-reduced-motion

Do not sacrifice performance for animation.

Target:

60 FPS scrolling on modern mobile and desktop devices.
